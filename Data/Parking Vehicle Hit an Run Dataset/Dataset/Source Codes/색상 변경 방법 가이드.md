# 물피도주 감지 시스템: 데이터 증강 변조 세트 가이드

> 원본 820개 영상에 대해 아래 5가지 변조 세트를 각각 1:1로 적용합니다.
> **총 데이터 규모: 원본 포함 6세트 × 820개 = 4,920개**

---

## 변조 세트 구성

| 세트 | 이름 | 핵심 변조 | 시뮬레이션 상황 |
|---|---|---|---|
| **원본** | Original | 없음 | 맑은 낮 |
| **세트 A** | Night | 감마 보정 + 가우시안 노이즈 | 일반적인 야간 |
| **세트 B** | Sodium Light | 감마 + 주황 색조 (HSV Hue +30) | 나트륨 가로등 아래 야간 |
| **세트 C** | LED Light | 감마 + 차가운 파란빛 (HSV Hue -30) | LED 가로등 아래 야간 |
| **세트 D** | Fog | 채도 감소 + 약한 블러 + 밝기 소폭 감소 | 안개 낀 낮/저녁 |
| **세트 E** | Rainy Night | 감마 + 노이즈 + 채도 감소 + 노면 반사 | 비 오는 야간 |

---

## 세트별 구현 방법

각 세트 내에서 영상마다 파라미터를 무작위 샘플링하여 세트 내 다양성을 추가 확보합니다.

---

### 세트 A — Night (일반 야간)

밤에는 빛의 양 자체가 줄어들기 때문에, 단순히 밝기를 균일하게 낮추는 것만으로는 실제 야간과 다른 결과가 나옵니다. 감마 보정(`V_out = (V_in / 255)^γ × 255`)을 적용하면 어두운 영역은 더 급격히 어두워지고 밝은 영역은 상대적으로 덜 어두워져, 실제 밤하늘의 명암 분포에 가까워집니다. 여기에 저조도 환경에서 이미지 센서가 발생시키는 열 잡음(Thermal Noise)을 흉내 내기 위해 각 픽셀에 가우시안 노이즈 `N(0, σ²)`를 더합니다. CCTV 영상 특유의 자글자글한 입자감이 바로 이 노이즈 때문입니다. OpenCV에서는 `cv2.LUT()`로 감마 룩업 테이블을 미리 만들어두면 프레임 처리 속도를 높일 수 있습니다.

```python
import random
gamma       = random.uniform(2.0, 3.0)
noise_sigma = random.uniform(8, 20)
```

---

### 세트 B — Sodium Light (나트륨 가로등, 주황빛)

도로변의 오래된 가로등 대부분은 나트륨 증기등으로, 약 589nm 파장의 강한 주황빛을 냅니다. 이를 구현하기 위해 RGB 영상을 HSV 색 공간으로 변환한 뒤 H(Hue) 채널을 +25°~+40° 시프트합니다. HSV는 색상·채도·명도를 독립적으로 조절할 수 있어서, "밝기는 그대로 두고 색깔만 주황으로 바꾸는" 작업이 RGB보다 훨씬 직관적입니다. S(Saturation) 채널을 소폭 높이면 나트륨등 특유의 짙은 색감도 표현됩니다. 시프트 후 H 값이 180을 넘으면 `% 180`으로 래핑(Wrapping) 처리해야 색상이 엉뚱하게 튀지 않습니다.

```python
gamma      = random.uniform(1.8, 2.8)
hue_shift  = random.uniform(25, 40)
saturation = random.uniform(1.05, 1.20)
```

---

### 세트 C — LED Light (LED 가로등, 파란빛)

세트 B와 같은 HSV 파이프라인을 사용하되, H 채널을 반대 방향(-25°~-40°)으로 시프트합니다. 현대 LED 가로등은 색온도 5,000~6,500K의 차가운 백색광을 내는데, 이 차가운 느낌이 HSV에서 Hue 감소(파란 계열)로 표현됩니다. S 채널을 소폭 낮추면 LED 특유의 탈색된 듯한 느낌도 살아납니다. H 값이 음수가 되는 경우에는 180을 더해 래핑합니다.

```python
gamma      = random.uniform(1.8, 2.8)
hue_shift  = random.uniform(-40, -25)
saturation = random.uniform(0.85, 0.95)
```

---

### 세트 D — Fog (안개)

안개는 공기 중 수분 입자가 빛을 산란시켜 발생하며, 물리적으로는 Koschmieder 대기 산란 모델로 설명됩니다. 실제 구현에서는 이를 세 가지 효과로 근사합니다. 첫째, S(Saturation) 채널을 크게 낮춰 색이 바랜 것처럼 만듭니다. 둘째, 가우시안 블러를 적용해 윤곽선이 뭉개지는 효과를 냅니다(커널 크기는 홀수여야 합니다). 셋째, 밝기를 아주 소폭만 낮춥니다. 안개는 어두운 게 아니라 뿌연 것이기 때문에, 야간 세트처럼 크게 어둡게 만들면 부자연스럽습니다.

```python
brightness = random.uniform(0.85, 0.95)
saturation = random.uniform(0.4, 0.65)
blur_ksize = random.choice([3, 5, 7])    # 커널은 홀수만
```

---

### 세트 E — Rainy Night (비 오는 야간)

비 오는 밤은 앞선 세트들의 효과가 복합적으로 나타나는 가장 까다로운 환경입니다. 세트 A의 감마 보정과 노이즈, 세트 D의 채도 감소를 먼저 적용한 뒤, 노면 반사를 추가합니다. 노면 반사는 영상 하단 약 40%를 도로 영역으로 가정하고, 그 영역을 수직 플립(Vertical Flip)한 후 수평 방향 랜덤 변위(Displacement Map)로 물결 왜곡을 준 뒤 `cv2.addWeighted()`로 원본과 블렌딩하는 방식으로 구현합니다. 영상이다 보니 프레임 간 물결 파라미터가 갑자기 바뀌면 영상이 깜빡이는 것처럼 보일 수 있으므로, 프레임 간 값을 선형 보간(Linear Interpolation)으로 부드럽게 이어줘야 합니다.

```python
gamma            = random.uniform(2.0, 3.0)
noise_sigma      = random.uniform(10, 25)
saturation       = random.uniform(0.5, 0.7)
reflection_alpha = random.uniform(0.15, 0.35)
```

> **단계적 구현 권장**: 노면 반사 없이 감마 + 노이즈 + 채도 감소만 먼저 완성하고, 이후 반사 효과를 추가하는 방식을 권장합니다.

## 주의사항

1. **시각적 검수**: 증강 후 일부 샘플은 육안으로 확인하여 차량이 식별 불가능한 수준으로 변형되지 않았는지 점검합니다.
2. **극단값 회피**: 감마값이 너무 크면 영상 전체가 검은색으로 포화됩니다. 적용 후 픽셀 분포를 확인하세요.
3. **레이블 보존**: 색상·명도 변환은 픽셀 좌표를 바꾸지 않으므로 바운딩 박스 레이블은 그대로 사용 가능합니다.
4. **원본 보존**: 원본 820개는 별도 폴더에 보존하고, 증강 데이터는 분리된 디렉터리에 저장합니다.
