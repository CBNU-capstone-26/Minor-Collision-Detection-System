# requirements.txt
# 물피도주 자동감지 "웹 서비스" 전체 스택 (웹 + Celery 워커 + ML 추론)
# 재현 검증 환경: Python 3.11.15 (Linux/WSL2, CPU 추론)
#
# 이 파일은 서비스 실행용(CPU)입니다. GPU 학습 환경은 별도 환경에서 관리하세요.
# Python 3.12+/3.14 는 torch 휠 미제공 가능성이 있으므로 Python 3.11 환경을 권장합니다.
# ================================================================
#
# -- 웹 서비스 실행에 필요한 프로젝트 구성 -------------------------
#   capstone-26/
#   ├── backend/           [필수] FastAPI 웹 + Celery 워커
#   ├── model/             [필수] 추론 코드
#   ├── weights/           [필수] 학습된 가중치
#   ├── ui/                [필수] 프론트엔드 소스
#   ├── docker-compose.yml [필수] MySQL8 + Redis 기동
#   └── requirements.txt   [필수] Python 3.11 환경 구성용
#
#   자동/로컬 생성 항목:
#   - storage/             업로드 원본/CAM 클립
#   - venv311/             Python 3.11 가상환경
#   - ui/node_modules/     npm install 로 생성
#
# 실행 전제: Docker, Node.js(+npm), uv(또는 python3.11)가 설치되어 있어야 합니다.
#
# -- 처음부터 실행하는 전체 순서 ----------------------------------
#   docker compose up -d db redis
#   uv venv --python 3.11 venv311
#   uv pip install --python venv311 -r requirements.txt
#   uv pip install --python venv311 \
#       --index-url https://download.pytorch.org/whl/cpu torch==2.12.0 torchvision==0.27.0
#   cd backend && ../venv311/bin/python -m uvicorn app.main:app --port 8000
#   cd backend && ../venv311/bin/celery -A app.worker worker --concurrency=1
#   cd ui && npm install && npm run dev
#
# torch/torchvision 은 PyTorch 전용 인덱스에서 받아야 하므로 별도 스텝으로 설치합니다.
# PyPI 일반 패키지와 인덱스가 달라 한 requirements 파일에 섞으면 uv 인덱스 정책과 충돌할 수 있습니다.
#
# -- 일반 venv/pip 사용 시 ---------------------------------------
#   python3.11 -m venv venv311 && source venv311/bin/activate
#   pip install -r requirements.txt
#   pip install --index-url https://download.pytorch.org/whl/cpu torch==2.12.0 torchvision==0.27.0
#
# macOS: 위 torch 명령 그대로 사용 가능(맥은 CPU 휠이 기본).
# GPU(CUDA)로 추론하려면 --index-url 을 https://download.pytorch.org/whl/cu121 등으로 바꾸고
# model/config.py 의 INFER_DEVICE_TYPE="cuda" 로 설정하세요.
# ================================================================
